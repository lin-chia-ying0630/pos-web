# 前端欄位長度定義

本檔集中盤點前端欄位容量與共用清單的語意寬度。後端 metadata 提供型態、長度與精度；`src/utils/fieldLayout.ts` 將資料契約轉為 `compact`、`normal`、`wide`，實際像素只由 `src/style.scss` 的 design token 管理。不得再依欄位英文 key 建立像素對照表。

## 表單資料長度（不是表格欄寬）

- 保單新增／修改表單使用 `src/components/PolicyMaintenanceDialog.vue`。
- `PolicyMaintenanceDialog.vue` 呼叫 `/api/policy-ui-metadata/{entity}`，將 API 的 `maxLength` 套到輸入欄位，並顯示 `description`。
- API 的型別、長度／精度與說明來自 `main.code_definition` 的 `UI-field-master`、`UI-field-address`、`UI-field-ride`。
- 後端只有在 `code_definition` 建立該欄位設定時才檢查；沒有設定就略過，不得因此中斷頁面。
- DB 資料長度與前端表單限制必須一致；像素欄寬仍只由共用 SCSS token 管理。

這裡的「欄寬」是畫面像素，不是資料庫長度。文字最大長度、整數／小數 precision、scale、必填與合法值仍由後端資料契約與 API 驗證；前端欄寬不得取代資料檢核。

## 適用元件與畫面

- 執行元件：`src/components/ScrollableRecordTable.vue` 與 `src/components/PolicyEntitySummary.vue`。
- `PolicyEntitySummary` 依 API metadata 呼叫 `fieldWidthToken`；`ScrollableRecordTable` 只接受語意 token，不接受頁面自行指定像素。
- 目前使用畫面：代碼對照表 `CodeQueryView.vue`，以及保單主檔、保單地址、保單主附約共用的 `PolicyEntitySummary.vue`。
- 後續新增共用清單時，只傳 `key`、資料契約、數字對齊與操作插槽；不可在 View 自行加入像素寬度。

## 共用清單語意欄寬

| 資料契約                                        | token     | 典型用途                 |
| ----------------------------------------------- | --------- | ------------------------ |
| `text/select` 且 `maxLength <= 10`              | `compact` | 短代碼、旗標、短序號     |
| `number` 且 `precision <= 10`                   | `compact` | 小型整數                 |
| `text/select` 且 `10 < maxLength <= 64`         | `normal`  | 一般文字、識別碼         |
| `number` 且 `precision > 10`                    | `normal`  | 金額及大型數字           |
| `datetime` 或 `text/select` 且 `maxLength > 64` | `wide`    | 日期時間、地址、長說明   |
| 操作欄                                          | `wide`    | 多個按鈕；只在插槽中使用 |

API 未提供 metadata 時，共用表格可依目前資料最大字數暫時判斷 token；這只是顯示回退，不可取代後端驗證。補齊 metadata 後應自動改由正式契約決定。

## 表單寬度級距

維護表單使用 `src/style.scss` 的共用 design token，不在頁面另設尺寸：

| token                   |  寬度 | 用途                 |
| ----------------------- | ----: | -------------------- |
| `--field-width-compact` | 120px | 短代碼、旗標、短序號 |
| `--field-width-normal`  | 180px | 一般文字與數字欄位   |
| `--field-width-wide`    | 320px | 地址、長說明等長內容 |

## 變更檢查

1. 修改資料容量時同步更新 DB、API metadata 與本檔；像素只修改 SCSS design token。
2. 保持資料一筆一行、欄位文字不互相覆蓋，超寬時使用表格底部橫向拉軸。
3. 補 `fieldLayout.test.ts` 的邊界測試，並使用最長既有值驗證。
4. 執行 format、lint、unit test、build 與欄距端對端測試。
